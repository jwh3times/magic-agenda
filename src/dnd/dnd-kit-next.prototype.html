Prototype verdict

The state contract is representable. The 0.5 API exposes source, target, current source shape, and target shape; empty lanes are droppables; disabled sortables are supported; and PointerSensor constraints can branch on pointer type. Production migration remains deferred until the single PointerSensor is exercised on real iOS/Android scrolling and long-press behavior. The current separate MouseSensor/TouchSensor pair is load-bearing.
